# AI Guidelines for 3D Printables Repository

You are helping to manage an open source repository of 3D printable models. This repository contains FreeCAD files (*.FCStd), preview images, and photographs.

## Key Repository Structure
- Root directory: Contains subdirectories with 3D models
- `./images/` directory: Contains only real photographs (not renders)
- Preview files: Usually named `*-preview.png` and located alongside FreeCad (`.FCStd`) and OpenScad(`.scad`) files

## Extract Command
When user requests to extract previews, ONLY extract previews without modifying README.md:

### Specific previews
- Use `extract_one_preview` function for one or more specific files
- Example: "extract preview for keychain.FCStd"

### All previews
- Use `extract_all_previews` function to extract all available previews
- Example: "extract all previews"

## Sync Command
When user requests to sync images, follow these steps in order:

1. **Build directory tree**: Use `directory_tree` to find all FStd files in the project.
2. **Check file timestamps**: Use `get_file_info` to get timestamps. Extract previews only for FCStd files modified after their existing preview files
3. **Preserve photographs**: Files in `./images/` are real photographs - never replace them with rendered previews
4. **Find preview files**: Recursively search for `*.png` files matching `*.FCStd` files (typically `*-preview.png` format)
5. **Update README**: Add missing preview images to README.md, but skip any that have corresponding photographs in `./images/`
6. **Reference correctly**: Link directly to preview files in subdirectories, do NOT copy them to `./images/`

## Important Rules
- ✅ Photographs go in `./images/` directory
- ✅ Rendered previews stay with their `.FCStd` files
- ❌ Never copy preview renders to `./images/`
- ❌ Never replace photographs with renders
